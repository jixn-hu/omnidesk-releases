# OmniDesk 安装包

OmniDesk 是用于管理 Windows 远程桌面与 Linux SSH 的桌面工作台，支持多会话、公共凭据、远程文件管理、加密备份和 WebDAV 同步。无需注册官方账号即可使用本地连接功能。

本仓库仅用于分发安装包和更新说明，不包含客户端或账号后台源码。

## 下载与安装

在本仓库的 **Releases → Latest** 下载最新 Windows x64 安装版。当前版本为 **0.6.5**，文件名为 `OmniDesk-0.6.5-win-x64.exe`，无需 GitHub 登录。

安装前将以下结果与同页 `SHA256SUMS.txt` 对应行比较：

```powershell
Get-FileHash -LiteralPath '.\OmniDesk-0.6.5-win-x64.exe' -Algorithm SHA256
```

安装程序尚未数字签名。请核对来源和校验值，不要关闭 Windows 防护。升级前导出加密配置备份并保存备份密码，结束会话、退出旧版后再安装；不要删除本机连接或公共凭据。

## 软件更新

从 0.6.2 开始，「设置 → 软件更新」使用默认更新源 `jixn-hu/omnidesk-releases`，只检查正式 Release。下载、安装均由用户确认，不会自动关闭远程会话，也不上传连接配置或凭据。旧版本首次迁移请从本仓库手动下载安装。

0.6.5 补齐 RDP 鼠标后退 / 前进侧键、同时按键、横向 / 高精度 / 快速滚动，以及远端 Ctrl+Shift 等组合键。保留服务器内部复制粘贴修复和手动接收文件：远端复制后只提示，点击「接收到本机」才下载。需要使用完整安装包，不混用旧运行库；本机操作系统保留的快捷键及服务器不支持的输入能力仍有平台限制。详见 Release 更新说明。

## 隐私与第三方组件

安装包不附带用户账号、密码、私钥或服务器配置；账号服务地址默认留空，由用户自行配置。仅发布安装包不代表无法逆向提取程序内容，不能把密钥放入应用中。

第三方组件保留各自许可证，详见程序内的开源许可及安装目录中的许可文件。请仅管理已获授权的服务器，不要为兼容而关闭服务器 NLA 或系统防护。
